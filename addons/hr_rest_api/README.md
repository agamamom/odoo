# HR REST API Module

This module provides a comprehensive RESTful API for the HR module in Odoo, allowing external applications to access HR data through standard HTTP requests.

## Features

- API endpoints for all major HR models (employees, departments, jobs, etc.)
- Secure authentication using API keys
- Support for GET, POST, PUT, and DELETE operations
- Pagination, sorting, and filtering options
- Consistent JSON response format

## API Endpoints

### Authentication

All API requests require an API key passed via the `API-Key` header.

### Employees

- **GET /api/hr/employees**: Get a list of employees
- **GET /api/hr/employees/{id}**: Get a specific employee by ID
- **POST /api/hr/employees**: Create a new employee
- **PUT /api/hr/employees/{id}**: Update an employee
- **DELETE /api/hr/employees/{id}**: Delete an employee

### Departments

- **GET /api/hr/departments**: Get a list of departments
- **GET /api/hr/departments/{id}**: Get a specific department by ID
- **POST /api/hr/departments**: Create a new department
- **PUT /api/hr/departments/{id}**: Update a department
- **DELETE /api/hr/departments/{id}**: Delete a department

### Job Positions

- **GET /api/hr/jobs**: Get a list of job positions
- **GET /api/hr/jobs/{id}**: Get a specific job position by ID
- **POST /api/hr/jobs**: Create a new job position
- **PUT /api/hr/jobs/{id}**: Update a job position
- **DELETE /api/hr/jobs/{id}**: Delete a job position

### Employee Categories

- **GET /api/hr/employee_categories**: Get a list of employee categories/tags

### Work Locations

- **GET /api/hr/work_locations**: Get a list of work locations

### Departure Reasons

- **GET /api/hr/departure_reasons**: Get a list of departure reasons

### Resource Calendars

- **GET /api/hr/resource_calendars**: Get a list of resource calendars (work schedules)

## Usage Examples

### Get list of employees

```bash
curl -X GET \
  "http://localhost:8069/api/hr/employees" \
  -H "API-Key: your_api_key_here"
```

### Create a new employee

```bash
curl -X POST \
  "http://localhost:8069/api/hr/employees" \
  -H "API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "job_title": "Software Developer",
    "department_id": 1,
    "work_email": "john.doe@example.com"
  }'
```

### Update an employee

```bash
curl -X PUT \
  "http://localhost:8069/api/hr/employees/1" \
  -H "API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "job_title": "Senior Software Developer"
  }'
```

### Delete an employee

```bash
curl -X DELETE \
  "http://localhost:8069/api/hr/employees/1" \
  -H "API-Key: your_api_key_here"
```

## Setup

1. Install the module in Odoo
2. Go to Settings > Users & Companies > Users
3. Select a user and go to the "HR REST API" tab
4. Click "Generate API Key" to create an API key for the user
5. Use this API key in your HTTP requests via the `API-Key` header

## Security

- API keys can only be generated by administrators
- API keys provide the same access level as the associated user
- Consider using HTTPS to secure your API communications
